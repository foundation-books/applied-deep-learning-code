# TensorFlow Playground Chapter Companion Note

This chapter is intentionally a browser lab rather than a Python notebook. Use
TensorFlow Playground at:

https://playground.tensorflow.org/

The chapter's reproducible artifact is the recorded experiment setting, not a
local script. A reader report should include the dataset, feature choices,
network architecture, activation, regularization, learning rate, training
steps, train/test loss, screenshots when useful, and a short explanation of the
decision boundary.

Later chapters translate the same ideas into runnable Python companion code.
