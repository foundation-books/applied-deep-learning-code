# Neural Network Training Reference Artifacts

The `table5-4/` directory mirrors the compact bounded-run artifacts cited by the
chapter's measured CIFAR-10 training table. It includes per-run history CSVs,
training-curve PNGs, confusion matrices, per-class accuracy CSVs, and metadata
text files.

The notebook and shared CIFAR runner can write fresh artifacts under local
`runs/` directories. These committed files are the small records used by the
book table.
