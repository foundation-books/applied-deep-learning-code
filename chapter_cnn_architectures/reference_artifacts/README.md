# CNN Architecture Reference Artifacts

This directory contains compact reference records cited by the CNN
architectures chapter.

- `cnn-architecture-quantitative-comparison.csv` is the source-noted scale table
  for common CNN variants.
- `resnet50-cifar10-pytorch/` contains the bounded ResNet50 CIFAR-10
  verification artifacts: history, training curves, confusion matrix,
  per-class accuracy, and metadata.

The companion scripts can regenerate artifacts for new runs under their own
output directories. These files are the small records used by the book tables.
