# Image Generation Reference Artifacts

This directory mirrors the compact JSON and CSV records cited by the image
generation chapter tables:

- `thor1-imagegen-result-values.json`
- `thor1-imagegen-ablation-table.csv`
- `thor1-imagegen-runtime-memory-table.csv`

The chapter PDF contains the rendered figure grids. Larger generated outputs and
new experiment runs should stay in local run directories unless they are
intentionally promoted to reader-facing artifacts.

The `thor1-*` filenames are historical artifact names retained for compatibility
with the book text and scripts; public metadata inside the files does not record
private hostnames.
