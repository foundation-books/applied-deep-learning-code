# Food-101 fast.ai Reference Artifacts

This directory contains compact records for the measured ResNet34 Food-101
validation baseline cited by the transfer-learning chapter.

`food101-fastai/food101-baseline.csv` is the summary printed in the book table.
The same directory also includes the command, version, metadata, and metrics
records used to support the reported runtime and software context. Larger raw
run artifacts and image-level error-analysis outputs are not committed.
