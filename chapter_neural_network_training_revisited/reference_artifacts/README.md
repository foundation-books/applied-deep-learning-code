# Neural Network Training Revisited Reference Artifacts

This directory mirrors the compact CUDA reference artifacts used by the
neural-network-training revisited case study. The files are provided so readers
with only the PDF and companion-code repository can inspect the CSV, JSON, and
PNG records referenced by the chapter without needing the book source tree.

The `thor1-nntrev-*` files retain their historical names for compatibility with
the book text and scripts. Raw AG News text is redacted from the public
error-example CSV because the upstream redistribution terms are unclear. The
`nntrev-reference-*` PNGs are the neutral figure names used in the book.
